# Александр Фаресов — личный лендинг

Личный лендинг-визитка директора по маркетингу Александра Фаресова. Ссылка на эту страницу прикладывается к откликам на вакансии Head of Marketing и отправляется тёплым контактам.

Структура: постоянная шапка (имя, титул, контакты, портрет) + две вкладки —
«Что я приношу» (профессиональный слой) и «Кто я и как веду» (человеческий слой), CTA в Telegram внизу обеих.

## Стек

Один самодостаточный статический файл — HTML/CSS/JS без сборки и фреймворков, специально для тривиального деплоя на GitHub Pages. Стиль «Редакция» собран на дизайн-системе SoulArk (`doc-system.css`).

## Запуск локально

Открыть `index.html` в браузере — рядом должны лежать `doc-system.css`, `fonts/`, `assets/`.

## Деплой

GitHub Pages из корня ветки `main` — `index.html` уже на месте.

## Файлы

- `index.html` — разметка, страничные стили и JS вкладок
- `doc-system.css`, `fonts/`, `assets/` — стили, шрифты и изображения
- `project/` — исходный хэндофф-бандл из Claude Design (референс дизайна и копирайта)
- `chats/` — транскрипт обсуждения дизайна
